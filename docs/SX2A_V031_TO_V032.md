# SX2A v0.3.1 → v0.3.2: what changed

On the Odin 3 Ultra, the official SX2A **v0.3.2** APK runs Switch 2 games, while our
build 49 (SX2A **v0.3.1**, commit `904bfa2`, plus our packaging) showed a black screen,
0 FPS and no sound. So the fix is somewhere in the 56 upstream commits below.

- v0.3.1: `904bfa266c23814660336db6bb0e87caf1c15305` (tag `nx2-android-v0.3.1`, after upstream's history rewrite)
- v0.3.2: `dd3cb327c79f511830e460b916a45a33b5738759` (tag `nx2-android-v0.3.2`, final upstream release)
- Merge base of v0.3.2 with our current Eglantine pin `3bdd53d`: `6e7edd7` (2026-10-30). Eglantine
  has none of SX2A's Android-specific work after that point.

Branch `claude/sx2a-v032` builds v0.3.2 exactly, with only `configure-sx2a.py`
(version/updater/package ID), as a known-good baseline to compare against.

## Likely relevant to a black screen / no sound at boot

- `ffbe148670` nx2:gpu: create graphics devices and report an empty gsv partition
- `f105f3041a` nvhost_ctrl_gpu: implement VSMS_MAPPING
- `75a9a2c2d9` nx2: report the class family flags in the GPU characteristics
- `998c4b6d5b` audio_core: accept the Switch 2 audio renderer revision
- `785acf7042` nvhost_as_gpu: share Switch 2 device ranges between a process's address spaces
- `5f2e0f0f81` vulkan_device: keep an integrated GPU's budget within its memory share
- `809670e3a5`, `095b17b756`, `2359f3ada7`, `01226f4e94`, `5b88db6806` nx2:vi2 present pacing, crop, output format, max resolution
- `838fc14705` and following: sparse texture tiles (nx2:gpu 216)
